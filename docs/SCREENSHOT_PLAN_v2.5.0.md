### Approved presentation choices

- No single-window screenshot; document the mode in text.
- No extra dark-mode/transfer-window screenshot is required for this set.
- Diagnostics intentionally shows the phone card before Environment check, not a scrcpy-version result.
- The connection page keeps the default-size lower-edge clipping.
- Updated English main/DeX captures show the complete Help label; English diagnostics no longer mixes Korean.
- Connected Companion home shots replace the earlier waiting-state captures.

### Image handling and privacy

README/guide captions identify language/state and do not claim all OS/device combinations.
The connection address shown is a capture example, not a value to copy to another phone.
No pairing code, token, private conversation or unique phone serial is exposed in the selected set.
Native Android examples can differ on other firmware.

Screenshots are GitHub documentation assets, never binary-ZIP content.
Old app captures are backed up and retired from current references; historical Git/review records retain provenance.
