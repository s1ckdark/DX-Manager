# Isolated Windows 7 font comparison / 독립 글꼴 비교

> Historical scope — current documentation at [the documentation index](README.md). This dated record describes its own build/artifact/state; current2.5.0 behavior and checksums are in the user guides and verification record.
> 과거 시점의 작업 기록입니다. 현재 동작·파일 해시는 문서 목차의2.5.0 안내를 따릅니다.


The user reports damaged text strokes across main/settings/help on a company
Windows 7 SP1 PC, 24-inch FHD at 100% scaling. Log body text is normal. The image
provided earlier was a Paint approximation, not a capture from that PC. No exact
root cause has been established. The scrcpy5 test and frozen2.5.0 use the same
DXManager executable; decoder changes do not change the app's UI font payload.

User requested a separate executable, rather than another DX Manager trial build.
`scripts/Build-FontLab.ps1` compiles `scripts/FontLab/FontLab.cs` with x64/.NET4.6.2
reference assemblies and the product manifest. No product/Store/APK source changes.

## Comparison modes

| Mode | Change from baseline |
| --- | --- |
| A | Current static Pretendard files, original memory registration/FontFamily creation, native GDI Label and TextRenderer |
| B | Malgun Gothic, same GDI and UI paint paths |
| C | Same Pretendard/GDI; quantize font sizes to integer pixels at96DPI |
| D | Same Pretendard; GDI+ DrawString with AntiAliasGridFit |
| E | Same Pretendard; GDI+ DrawString with ClearTypeGridFit |
| F | Same as A; exclude WS_EX_COMPOSITED from BufferedPanel |

Main uses the1200x800 outer-window sizing helper and the original client-size font
fit formula; help uses the1040x760 helper followed by the original Sizable border
change. Observed outer/client sizes are included in result text, since nonclient
metrics vary by OS/theme. The fixture is a representative UI, not the whole app:
resolution/app inputs are sample buttons, and no live sessions/settings are loaded.
Help reuses native AutoSize labels/flow panels, layered cards, themed menu buttons,
the redraw freeze and scrollbar code. Glyph rows include both weights and a fixed
Consolas13px-derived RichTextBox log baseline. Pixels<=18 retain UiFonts' extra pixel.

Generated copies preserve the production implementations, with explicit adapters:
- UiFonts is renamed BaselineUiFonts; its native registration call records the
  returned handle/count without changing allocation or family-selection behavior.
- ThemedControls text calls forward to the original TextRenderer in A/B/C/F;
  D/E substitute measured/drawn GDI+ text. Native labels change only in D/E.
- DesktopSurface's product-form type check recognizes the fixture form instead.
- BufferedPanel's composition flag is conditional only in F.
- ThemeColors, UiWindowStyle and FluentIconRenderer are copied unchanged.
- The exact regular/semi-bold TTFs and31 icons are embedded; source hashes and
  OFL/MIT notices accompany the package. No fonts are installed system-wide.

Font-name construction was tried during development, but it selected Microsoft
Sans Serif on this Windows11 host instead of the private font. That experiment
was removed; delivered C is integer-size GDI, not silent font fallback.

## 한국어 사용 순서

ZIP 전체를 풀고 DXFontLab.exe를 실행한다. 선택 창에서 A~F를 바꾸며 메인,
도움말, 글자표와 밝음/어두움 테마를 확인한다. 현재 Pretendard를 유지한
C/D/E/F 중 정상인 방법이 있는지를 먼저 비교하면 맑은 고딕으로 돌아갈 필요가
있는지 판단할 수 있다. F는 BufferedPanel 합성만 바꾸므로 도움말에 같은 변화가
반드시 생기는 것은 아니다.

정상/깨짐 버튼은 조건과 PC 환경을 임시 기록한다. 종료 전에 '결과 전체 복사'를
눌러 메모장에 저장하거나 채팅에 붙여넣는다. '화면 복사'는 그림판에 붙여넣어
저장할 수 있다. 기록은 앱 종료 시 사라진다. 회사 PC 결과를 보고 실제
DX Manager 수정 방법을 선택하며, 이 프로그램만으로 원인을 확정하지 않는다.
