## English

Experimental maximum120 FPS (default60) requires the phone screen on and confirmation
before every start. Heat, battery and OLED burn-in warnings are shown in the app.
Switching back to30/60 restores the prior screen-off preference.

- 64-bit Windows 7 SP1, 8.1, 10 or 11; .NET Framework 4.6.2 or newer.
- Keep this entire folder together and run DXManager.exe from a writable location.
- On first launch, read the notice, check the acknowledgement box and select Confirm and start.
  Accepting once is remembered. A fresh distribution contains no personal settings or acceptance record.
- Connect a DeX-capable Galaxy phone, enable USB debugging and approve the phone's prompt.
- Open Help / Troubleshooting in the app for setup, usage, recovery and FAQ.
- Use Settings > Companion to install/update the included official APK and grant its cleanup permission.
  This release requires the updated Companion for the improved notification shutdown behavior.
- Exit from the tray menu or use Left Alt+F8 before disconnecting the phone.
- Update checks run in the background once per day. Settings > About also offers a manual check.
- Required third-party notices are in licenses. Original scrcpy icons belong to its runtime.

Project and releases: https://github.com/maze-mei/DX-Manager
