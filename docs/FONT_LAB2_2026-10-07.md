> Historical scope — current documentation at [the documentation index](README.md). This dated record describes its own build/artifact/state; current2.5.0 behavior and checksums are in the user guides and verification record.
> 과거 시점의 작업 기록입니다. 현재 동작·파일 해시는 문서 목차의2.5.0 안내를 따릅니다.


User authorized a second standalone company test for October8. The first report
confirms Win7 SP1,96DPI/FHD, ClearType enabled and correct private-font registration
and actual GDI faces. Malgun Gothic was normal in the recorded conditions; A/C/D/E/F
Pretendard modes were marked damaged. Small GDI+ gray text was particularly poor,
while larger text looked normal in the supplied genuine company captures.

## New evidence and scope

Official Pretendard v1.3.9 static alternative TTFs were fetched from the author's
tagged repository. Both also lack gasp and glyph hint instructions. Thus missing
hinting/gasp in the current embedded fonts does not prove conversion lost them.
This is a size-dependent rasterization hypothesis, not an established root cause.

Build: `scripts/Build-FontLab2.ps1`. Uses the existing sample UI, fonts, themed
controls, .NET4.6.2 reference assemblies and x64 compiler. FONTLAB2 conditional
code supplies a fixed profile; the original first-test executable/package remains
unchanged. Product/Store/APK code and release2.5.0 are not rebuilt or changed.

| Profile | Font file | Rendering |
| --- | --- | --- |
| A2 | Current embedded TTFs unchanged | Original GDI |
| B2 | Current TTFs with gasp v1/0x000A, renamed | Original GDI |
| C2 | Official static v1.3.9 TTFs unchanged | Original GDI |
| D2 | Official TTFs with gasp v1/0x000A, renamed | Original GDI |
| E2 | Same files as B2 | GDI+ AntiAliasGridFit |
| F2 | Current TTFs unchanged | GDI+ AntiAlias, no hint/grid-fitting request |
| G2 | System Malgun Gothic | Original GDI |

gasp0x000A recommends grayscale and symmetric ClearType smoothing for all sizes,
without recommending grid fitting. It does not add TrueType hint programs and is
not guaranteed to override every renderer. B2/D2 preserve every table byte except
name, head checksum, gasp and the removed DSIG of modified official fonts. The
preparer asserts raw outline/layout-table equality, weight preservation and whole
SFNT checksum. Modified fonts have separate DX Lab2 family/PostScript names in
accordance with OFL; C2 remains the unmodified official baseline.

All variants retain the same sizes, fractional main font fit, UI layout/composition
and geometry. Only the stated font-file/rendering conditions change. Seven
separate executables isolate private GDI registration in separate processes;
the root GUI launcher permits one test process at a time. Runtime does not
install fonts, access the network, run ADB/Scrcpy or import product settings.

## 한국어 사용법

ZIP 전체를 새 폴더에 풀고 DXFontLab2.exe를 실행한다. A2~G2는 이전 A~F와
다른 번호이다. 처음에는 글자표가 열리므로 작은 글자의 획부터 비교한다.
B2/D2/E2/F2는 Pretendard를 유지할 수 있는지 보기 위한 새 조건이다.
각 조건에서 정상/깨짐을 기록하고 종료 전에 결과 전체 복사로 메모장에 추가한다.
큰 샘플 창뿐 아니라 작은 비교 선택 창도 닫고 다음 항목을 연다.
화면 복사 결과와 실제 보이는 깨짐이 다르면 Windows 캡처로 기록한다.
정상 후보가 있으면 메인·도움말·어두움 테마까지 확인한 후 본체 적용을 결정한다.
