# Generated official Companion snapshot

Do not edit Android implementation in this directory. It is exported from the canonical shared component.
For a maintainer change, read the canonical component's instructions/change history/release manifest, edit and verify there,
then run scripts/Export-CompanionSnapshot.ps1 from the repository root.
Preserve the official package/certificate and exact APK hash. Never add signing inputs, caches or the private AI test app.
Public source users may build personal debug variants; they cannot issue an officially signed update.
